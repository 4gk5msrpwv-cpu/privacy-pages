요약: KidsLearn은 어떠한 개인정보도 수집하지 않습니다. 계정 시스템, 서버, 제3자 분석·광고 SDK가 없습니다. 입력하신 시간표, 숙제, 습관, 알림, 포인트 데이터는 오직 본인의 개인 iCloud 데이터베이스(Apple CloudKit)에만 저장되며, 개발자는 이를 읽거나 내보낼 수 없습니다. 보호자 관리를 위한 어린이 기기 잠금(PIN)을 제공하며, 아동 관련 모든 콘텐츠는 보호자가 생성하고 관리합니다.

개인정보 처리방침

1. 개요

KidsLearn은 시간표, 숙제 기록, 습관 체크, 학습 알림, 포인트·보상 기능을 제공하는 학부모용 학습 관리 도구입니다. 개인 개발자(Frank Zhou)가 개발했으며, 자체 서버와 백엔드 데이터베이스가 없습니다. 본 방침은 저희가 회원님의 정보를 어떻게 처리하는지(정확히는 처리하지 않는지)를 설명합니다.

2. 수집하는 정보: 없음

KidsLearn은 어떠한 개인정보도 수집하지 않습니다. 구체적으로:

  • 가입 없음, 로그인 없음. 이름, 이메일, 전화번호, 연락처, 위치, 사진, 식별자 등을 요청하거나 받지 않습니다.
  • 데이터는 본인의 iCloud에만 보관됩니다. 시간표, 숙제, 습관, 알림, 포인트, 보상 등은 본인 Apple ID의 개인 iCloud 데이터베이스(Apple CloudKit, 컨테이너 iCloud.com.frankzhou.KidLearn)에 저장됩니다. 데이터는 회원님의 소유이며 Apple이 보관합니다. 개발자는 접근·열람·내보내기를 할 수 없습니다.
  • 가족 공유 및 ‘아이 공간’. Apple CloudKit의 CKShare를 기반으로 하며, 회원님이 명시적으로 초대한 Apple ID(통상 가족)하고만 공유됩니다. 공유 범위는 회원님이 관리하며 언제든 취소할 수 있습니다.

기기 기능 및 시스템 권한:

  • 알림: 회원님이 직접 설정한 학습 알림을 표시하는 데만 사용되며 광고나 마케팅 내용이 포함되지 않습니다. ‘원격 알림’은 iCloud 동기화를 위한 무음 트리거로만 사용되며 눈에 보이는 알림을 표시하지 않습니다.
  • 사진(시스템 사진 선택기): 숙제의 ‘텍스트 스캔(OCR)’ 기능은 Apple 시스템 사진 선택기(PhotosPicker)로 이미지를 선택합니다. 앱은 선택한 한 장만 받으며 보관함 전체를 훑어보거나 접근할 수 없고, 사진 보관함 권한도 필요하지 않습니다. 인식은 Apple Vision 프레임워크로 전적으로 기기 내에서 수행되며 이미지와 결과는 어떤 서버로도 전송되지 않고 원본 이미지도 보관하지 않습니다. 본 앱은 카메라를 사용하지 않으며 카메라 권한도 요청하지 않습니다. 아동 아바타 사진 설정도 같은 방식입니다: 선택한 한 장만 읽어 압축한 뒤 보호자 본인의 iCloud 계정에만 저장되며, 어떤 서버로도 전송되지 않습니다.
  • Face ID / Touch ID / 기기 암호: 보호자가 ‘어린이 모드 PIN’을 변경·재설정하거나 어린이 모드를 해제할 때 기기 본인 확인에만 사용됩니다. 인증은 iOS가 수행하며, 앱은 어떤 생체 정보도 수신·읽기·저장하지 않습니다.
  • 클립보드: 회원님이 직접 ‘붙여넣기’를 탭했을 때 한 번만 읽어 숙제 목록을 만드는 데 사용합니다. 텍스트는 기기 내에서 처리되며 전송되거나 보관되지 않습니다. 그 외에는 클립보드에 접근하지 않습니다.
  • 절대 요청하지 않는 권한: 위치, 연락처, 캘린더, 미리 알림, 마이크, 카메라, 앱 추적 권한. 위 항목 외에 앱이 선언한 권한은 없습니다.

3. 제3자 서비스, 추적, 광고: 없음

  • 제3자 코드 없음: 프로젝트는 어떤 Swift 패키지, CocoaPods, 제3자 라이브러리에도 의존하지 않습니다. 광고 SDK, 분석 SDK(Firebase 등), 크래시 수집, 어트리뷰션, 푸시 마케팅 구성요소가 없습니다.
  • 추적 없음: IDFA를 사용하지 않고 앱 추적 투명성 권한을 요청하지 않으며, 앱 간·사이트 간 추적, 추적용 쿠키, 기기 지문, 로컬 식별자를 사용하지 않습니다.
  • 사용자 데이터를 판매·공유·거래하지 않습니다. 어떤 형태의 데이터 수익화에도 참여하지 않으며 광고나 사용자 프로파일링에 사용하지 않습니다.
  • 이 정책 페이지를 불러오는 경우를 제외한 모든 네트워크 요청은 Apple 서비스로만 향합니다: iCloud(CloudKit) 동기화와 App Store 인앱 구매(StoreKit)입니다. 두 서비스는 Apple의 개인정보 처리방침에 따릅니다. Apple 개인정보 처리방침을 참조하세요. (앱 내 ‘개인정보 처리방침’과 ‘지원’ 항목은 주소 표시줄이 없는 내장 리더에서 열리며 외부 브라우저로 이동하지 않습니다. 이 페이지만 불러오고 JavaScript는 비활성화되며, 쿠키나 브라우징 데이터를 저장하지 않고 다른 도메인으로의 이동은 차단됩니다. 이 페이지는 제3자 정적 호스팅(GitHub Pages)에서 호스팅되며, 이를 불러오는 것이 앱에서 Apple 외 서비스로 향하는 유일한 네트워크 요청이고 계정·기기 식별자를 포함하지 않습니다.)

4. 아동(미성년자) 정보 보호

KidsLearn은 아동용 앱이 아닌 보호자용 관리 도구이며, 모든 콘텐츠는 보호자가 생성하고 관리합니다. 앱은 채팅, 댓글, 공개 프로필, 콘텐츠 탐색·추천, 낯선 이와의 상호작용, 사용자 생성 콘텐츠의 공개 공유 기능을 제공하지 않습니다.

  • 아동의 개인정보를 수집·판매하거나 제3자에게 공개하지 않습니다. 아동의 학습 기록(별명, 아바타, 과목, 숙제, 습관, 포인트 등)은 보호자가 입력하며 보호자 본인의 iCloud 계정에만 저장됩니다. 개발자는 접근할 수 없습니다.
  • 공개되는 사용자 생성 콘텐츠 없음. 보호자가 입력한 텍스트는 보호자가 iCloud 개인 공유(CKShare)로 일대일 초대한 가족에게만 표시됩니다. 공개 대상도, 낯선 이에 대한 공개도, 검색·추천 기능도 없어 공개 UGC와 관련된 사회적 위험이 없습니다.
  • 보호자 관리 기능. ‘어린이 기기 잠금(PIN)’을 켜면 설정 기능이 숨겨지고 해제하려면 PIN이 필요합니다. PIN 변경·재설정에는 시스템 생체 인증 또는 기기 암호가 필요합니다.
  • 아동용 Apple ID. 보호자가 아동용 Apple ID에 아이 공간을 공유하는 경우, 해당 계정은 Apple 규정에 따라 보호자가 생성·관리하며 공유는 항상 보호자가 관리하고 언제든 중단할 수 있습니다.
  • 보호자 동의에 관하여. 본 앱은 아동의 개인정보를 전혀 수집하지 않으므로, 미국 COPPA, EU GDPR(아동 관련 조항), 중국 ‘아동 개인정보 네트워크 보호 규정’이 요구하는 ‘확인 가능한 보호자 동의’ 절차가 적용되지 않으며, 이를 위해 보호자의 신원 정보를 수집할 필요도 없습니다. 보호자는 언제든 아이 공간과 그 모든 데이터를 삭제할 수 있으며 삭제는 즉시 반영됩니다.
  • 중국 「개인정보 보호법」과 「아동 개인정보 네트워크 보호 규정」을 준수하고 COPPA / GDPR 원칙에 맞춥니다: 최소 수집, 보호자 통제, 미공유, 미판매, 광고·프로파일링 미사용.
  • 아동 관련 정보를 열람·정정·완전 삭제하려는 보호자는 앱 내에서 직접 처리하거나 Your.Kidslearn@outlook.com로 문의하여 도움을 받을 수 있습니다.

5. 데이터 저장, 보안 및 삭제

  • 모든 데이터는 회원님 Apple ID의 iCloud 계정에 저장되며 Apple의 암호화 및 접근 제어로 보호됩니다. 서버 측 복사본은 보관하지 않습니다.
  • 앱을 삭제해도 iCloud 데이터는 자동으로 지워지지 않습니다(새 기기 복원을 위해). 모두 지우려면 iPhone/iPad에서 설정 → Apple ID → iCloud → 계정 저장 공간 관리 → KidsLearn → 데이터 삭제로 이동하거나, 앱 내 나 → 아이 공간에서 해당 공간을 삭제하거나, Your.Kidslearn@outlook.com로 삭제 지원을 요청하세요.
  • 일부 화면 설정(언어, 표시 설정)은 기기 로컬(시스템 UserDefaults)에 저장됩니다. 기기를 떠나지 않으며 iCloud와 동기화되지 않습니다.
  • Apple ID와 기기 잠금 암호를 안전하게 보관하세요. 이 데이터를 보호하는 주된 수단입니다.

6. 구매 및 결제

KidsLearn은 무료로 다운로드할 수 있고 7일 로컬 체험판을 제공합니다. 전체 버전은 1회 구매(비소모성, 구독 아님, 자동 갱신 없음)입니다. 모든 결제는 Apple App Store(StoreKit)가 처리하며, 결제 카드 정보를 받거나 저장하지 않습니다. 가족 공유가 활성화되어 있어 가족이 다시 구매할 필요가 없습니다.

7. 본 방침의 변경

본 방침이 변경되면 이 페이지를 갱신하고 상단의 ‘시행일’을 수정합니다. 중대한 변경(예: 새로운 데이터 수집 도입)은 앱 내에서도 눈에 띄는 방식으로 안내합니다. 최신 내용을 확인하려면 정기적으로 이 페이지를 방문해 주세요.

8. 문의

본 방침이나 데이터에 관한 질문, 불만, 삭제 요청은 Your.Kidslearn@outlook.com로 보내주세요. 통상 영업일 3일 이내에 회신합니다.

지원 및 자주 묻는 질문

새 기기 / 여러 기기 동기화각 기기에서 동일한 Apple ID로 로그인하고 iCloud 드라이브를 켜면 자동으로 동기화됩니다. 동기화가 멈추면 설정 → Apple ID → iCloud를 확인하세요.
가족 / 아이 공간 공유앱에서 ‘아이 공간 공유’(Apple CloudKit CKShare)를 사용하고, 상대가 자신의 Apple ID로 수락합니다. 테스트에는 서로 다른 Apple ID 2개가 필요합니다.
구매 복원결제 화면 하단의 ‘구매 복원’을 탭하세요. 추가 요금이 부과되지 않습니다.
모든 데이터 삭제위 5항을 참조하세요. 앱 삭제는 iCloud 데이터를 지우지 않습니다.
텍스트 스캔(OCR)Apple Vision으로 기기 내에서 전부 처리됩니다. 업로드도 네트워크 연결도 필요 없습니다.
지원 언어간체·번체 중국어, 영어, 일본어, 스페인어, 포르투갈어(브라질), 프랑스어, 독일어, 한국어, 러시아어(총 10개).
시스템 요구 사항iOS / iPadOS 17.0 이상(iPhone·iPad 공용, 홈 화면 위젯 포함).

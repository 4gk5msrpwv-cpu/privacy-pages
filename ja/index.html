プライバシーポリシー

1. 概要

KidsLearn は保護者向けの学習管理アプリです。時間割、宿題の記録、習慣のチェック、学習リマインダー、ポイント報酬などの機能を提供します。個人開発者（Frank Zhou）が開発しており、自社サーバーもバックエンドデータベースもありません。本ポリシーは、私たちがお客様の情報をどのように扱うか（実際には扱わないか）を説明するものです。

2. 収集する情報：ありません

KidsLearn は個人情報を一切収集しません。具体的には：

  • 登録不要・ログイン不要。氏名、メールアドレス、電話番号、連絡先、位置情報、写真、識別子などを求めることも取得することもありません。
  • データはお客様の iCloud にのみ。作成された時間割・宿題・習慣・リマインダー・ポイント・ごほうびは、お客様ご自身の Apple ID のプライベート iCloud データベース（Apple CloudKit、コンテナ iCloud.com.frankzhou.KidLearn）に保存されます。データはお客様に帰属し Apple が保管します。開発者がアクセス・閲覧・書き出しすることはできません。
  • ファミリー共有と「こどもスペース」。Apple CloudKit の CKShare を使用し、お客様が明示的に招待した Apple ID（通常はご家族）とのみ共有されます。共有範囲はお客様が管理し、いつでも停止できます。

端末機能とシステム権限：

  • 通知：お客様が設定した学習リマインダーの表示のみに使用し、広告やマーケティング内容は含まれません。「リモート通知」は iCloud 同期のきっかけ（サイレント通知）としてのみ使われ、画面に表示されることはありません。
  • 写真（システムの写真選択）：宿題の「文字認識」機能は Apple のシステム写真選択（PhotosPicker）で画像を選びます。アプリが受け取るのは選択された 1 枚のみで、ライブラリ全体を参照することはできず、写真ライブラリの権限も不要です。認識は Apple Vision によりすべて端末内で行われ、画像も結果もサーバーに送信されません。認識後に元画像を保持することもありません。カメラは使用せず、カメラ権限も要求しません。
  • Face ID / Touch ID / 端末パスコード：保護者が「こどもモード PIN」を変更・再設定する場合や、こどもモードを解除する場合の本人確認にのみ使用します。認証は iOS が行い、アプリが生体情報を取得・読み取り・保存することはありません。
  • ペーストボード：お客様が「貼り付け」をタップしたときに 1 度だけテキストを読み取り、宿題リストの作成に使います。端末内で処理し、送信も保存もありません。それ以外の場面でペーストボードにアクセスすることはありません。
  • 要求しない権限：位置情報、連絡先、カレンダー、リマインダー、マイク、カメラ、App トラッキングなどの権限は要求も使用もしません。

3. 第三者サービス・トラッキング・広告：なし

  • 第三者のコードは一切なし：Swift Package や CocoaPods など第三者ライブラリに依存せず、広告 SDK、解析 SDK（Firebase 等）、クラッシュ収集、アトリビューション、マーケティング配信の仕組みもありません。
  • トラッキングなし：IDFA を使用せず、App トラッキングの許可も要求しません。アプリ間・サイト間のトラッキング、トラッキング用 Cookie、指紋認証、ローカル識別子も使用しません。
  • データの販売・共有・取引は一切行いません。広告配信やユーザープロファイリングにも利用しません。
  • 本ポリシーページの読み込みを除き、すべての通信は Apple のサービス宛てのみ：iCloud（CloudKit）同期と App Store のアプリ内課金（StoreKit）です。いずれも Apple のプライバシーポリシーに従い処理されます。Apple のプライバシーポリシーをご確認ください。（アプリ内の「プライバシーポリシー」「サポート」はアドレスバーを表示しない内蔵リーダーで開き、外部ブラウザへは移動しません。読み込むのは本ページのみで、JavaScript は無効化され、Cookie や閲覧データは一切書き込まれず、他ドメインへの遷移はブロックされます。本ページは第三者の静的ホスティング（GitHub Pages）でホストされており、この読み込みが本アプリから Apple 以外のサービスへの唯一の通信です。アカウントや端末の識別子は送信されません。）

4. こども（未成年者）の情報保護

KidsLearn は保護者向けの管理ツールであり、こども向けアプリではありません。すべての内容は保護者が作成・管理します。チャット、コメント、公開プロフィール、コンテンツの発見・レコメンド、見知らぬ人との交流、ユーザー生成コンテンツの公開共有機能はありません。

  • こどもの個人情報を収集・販売・第三者開示することはありません。こどもの学習記録（ニックネーム、アバター、教科、宿題、習慣、ポイント等）は保護者が入力し、保護者自身の iCloud アカウントにのみ保存されます。開発者はアクセスできません。
  • 公開されるユーザー生成コンテンツはありません。保護者が入力したテキストは、保護者が iCloud プライベート共有（CKShare）で1 対 1 で招待した家族にのみ表示されます。一般公開も、見知らぬ人への公開も、検索・レコメンドもありません。
  • 保護者による管理機能。「こどもモード（PIN）」をオンにすると設定機能が隠され、解除には PIN が必要です。PIN の変更・再設定には生体認証または端末パスコードが必要です。
  • こども用 Apple ID。保護者がこども用 Apple ID にスペースを共有した場合、そのアカウントは Apple の規約に従い保護者が作成・管理するものであり、共有は常に保護者が管理し、いつでも停止できます。
  • 保護者の同意について。本アプリはこどもの個人情報を一切収集しないため、米国 COPPA、EU GDPR（こどもに関する規定）、中国「児童個人情報ネットワーク保護規定」が定める「検証可能な保護者の同意」の仕組みは適用されず、そのために保護者の身元情報を収集することもありません。保護者はいつでもこどもスペースとその全データを削除でき、即時に反映されます。
  • 中国「個人情報保護法」「児童個人情報ネットワーク保護規定」に従い、COPPA / GDPR の原則にも準拠します：最小限の収集、保護者による管理、共有しない、販売しない、広告やプロファイリングに利用しない。
  • こどもに関する情報の閲覧・訂正・完全削除をご希望の場合は、アプリ内で操作いただくか、fathyzhou@qq.com までご連絡ください。

5. データの保存・保護・削除

  • すべてのデータはお客様の Apple ID の iCloud アカウントに保存され、Apple の暗号化とアクセス制御で保護されます。サーバー側にコピーは保持しません。
  • アプリを削除しても iCloud のデータは自動的には消えません（機種変更時の復元のため）。完全に消去する場合は、iPhone / iPad の「設定 → Apple ID → iCloud → アカウントのストレージを管理 → KidsLearn → データを削除」、またはアプリ内の「マイページ → こどもスペース」から該当スペースを削除してください。fathyzhou@qq.com までご連絡いただいても対応します。
  • 一部の表示設定（言語など）は端末内のシステム UserDefaults に保存されます。端末外に出ることはなく、iCloud とも同期しません。
  • Apple ID と端末のロック解除パスコードを適切に管理してください。これらがデータを守る主な手段です。

6. 購入とお支払い

KidsLearn は無料でダウンロードでき、7 日間のローカル試用期間があります。完全版は買い切り型（非消費型・非サブスクリプション、自動更新なし）です。お支払いは Apple App Store（StoreKit）が処理し、クレジットカード情報を取得・保存することはありません。ファミリー共有に対応しているため、ご家族が重複して購入する必要はありません。

7. ポリシーの変更

本ポリシーを変更した場合は、このページを更新し上部の「施行日」を改めます。重要な変更（新しいデータ収集の開始など）については、アプリ内でも目立つ形でお知らせします。最新の内容をご確認いただくため、定期的にこのページをご覧ください。

8. お問い合わせ

本ポリシーやデータの取り扱いに関するご質問・苦情・削除のご要望は fathyzhou@qq.com までご連絡ください。通常 3 営業日以内に返信いたします。

サポート・よくあるご質問

機種変更・複数端末での同期各端末で同じ Apple ID でサインインし、iCloud ドライブを有効にすると自動的に同期されます。同期しない場合は「設定 → Apple ID → iCloud」をご確認ください。
家族・こどもスペースの共有アプリ内の「こどもスペースを共有」（Apple CloudKit CKShare）を使用し、相手が自分の Apple ID で受け入れます。テストには 2 つの異なる Apple ID が必要です。
購入の復元購入画面下部の「購入を復元」をタップしてください。重複して課金されることはありません。
データの完全削除上記「5. データの保存・保護・削除」をご覧ください。アプリの削除では iCloud のデータは消えません。
文字認識（OCR）Apple Vision により端末内で処理します。アップロードもネットワーク接続も不要です。
対応言語簡体字中国語、繁体字中国語、英語、日本語、スペイン語、ポルトガル語（ブラジル）、フランス語、ドイツ語、韓国語、ロシア語（全 10 言語）。
システム要件iOS / iPadOS 17.0 以降（iPhone と iPad 対応、ホーム画面ウィジェットを含む）。

一句話總結：KidsLearn 不收集任何個人資訊。沒有帳號系統、沒有伺服器、沒有第三方統計或廣告 SDK。你錄入的課程表、作業、習慣、提醒與積分資料，只儲存在你自己的 iCloud 私人資料庫（Apple CloudKit）中，開發者無法讀取或匯出。應用內建兒童裝置鎖（PIN）等家長控制功能，兒童相關內容一律由家長建立與管理。

隱私政策

一、概述

KidsLearn 是一款面向家長的兒童學習管理工具，提供課程表、作業記錄、習慣打卡、學習提醒與積分獎勵等功能。本應用由個人開發者（Frank Zhou）獨立開發，無自建伺服器、無後臺資料庫。本政策說明我們如何處理（事實上是：不處理）你的資訊。

二、我們收集哪些資訊：不收集

KidsLearn 不主動收集任何個人資訊。具體而言：

  • 無需註冊、無需登入：不要求也不獲取姓名、電子郵件、手機號碼、通訊錄、位置、相簿、身份標識等資訊。
  • 學習資料僅存於你的 iCloud：你建立的課程表、作業、習慣、提醒、積分與獎品等內容，儲存在你本人 Apple ID 下的 iCloud 私人資料庫（Apple CloudKit，容器 iCloud.com.frankzhou.KidLearn）。這些資料歸你所有，由 Apple 保管，開發者無法訪問、讀取或匯出。
  • 家庭共享與「孩子空間」：基於 Apple CloudKit 的 CKShare 實現，資料僅在你主動邀請的 Apple ID（通常是家庭成員）之間共享，共享範圍完全由你控制，可隨時停止共享。

裝置能力與系統權限：

  • 通知：用於展示你自行設定的學習提醒，僅在你開啟後使用，不含任何廣告或營銷內容。其中「遠端通知」僅用作 iCloud 資料同步的觸發訊號（靜默通知），不會產生任何可見提示，也不承載任何內容。
  • 相簿（系統照片選擇器）：作業清單的「圖片識字」功能透過 Apple 系統照片選擇器（PhotosPicker）挑選圖片，App 只會拿到你選中的那一張，無法瀏覽或訪問相簿中的其他照片，也無需你授予相簿權限。文字識別由 Apple Vision 框架完全在裝置端完成，圖片與識別結果不上傳任何伺服器，識別後不保留原圖。本應用不使用相機，也不申請相機權限。
  • 面容 ID / 觸控 ID / 裝置密碼：僅在家長修改或重置「兒童裝置鎖 PIN」、以及關閉兒童模式時，用於本機身份驗證。驗證由 iOS 系統完成，App 不會收到、也無法讀取或儲存任何生物特徵資訊。
  • 剪貼簿：僅在你主動點選「貼上」按鈕時讀取一次剪貼簿中的文字，用於生成作業清單；讀取後即在裝置端處理，不上傳、不長期儲存。除此之外本應用不會訪問剪貼簿。
  • 不申請的權限：本應用不申請、不使用定位、通訊錄、日曆、提醒事項、麥克風、相機、藍芽跟蹤（App 追蹤透明度）等權限，工程內除上述項外無任何權限宣告。

三、第三方服務、追蹤與廣告：無

  • 本應用不含任何第三方程式碼庫或 SDK：工程不依賴任何第三方包（無 Swift Package、無 CocoaPods），也不含廣告 SDK、資料分析 SDK（如 Firebase、友盟等）、崩潰統計、歸因或推送營銷元件。
  • 不追蹤：不使用 IDFA，不申請 App 追蹤透明度授權，不進行跨應用或跨網站追蹤，不設定用於追蹤的 Cookie、裝置指紋或本地標識。
  • 不出售、不共享、不交易任何使用者資料；本應用不參與任何形式的資料商業化，也不將資料用於廣告投放或使用者畫像。
  • 應用發起的全部網路請求均指向 Apple 官方服務：iCloud（CloudKit）資料同步，以及 App Store 內購（StoreKit）。二者均由 Apple 按其自身隱私政策處理，詳見 Apple 隱私政策。（應用內「隱私政策」「支援與反饋」入口透過系統應用內瀏覽器開啟，頁面由 Safari 渲染引擎在獨立程序中載入，本應用無法讀取頁面內容、Cookie 或瀏覽歷史，也不注入任何指令碼。）

四、兒童（未成年人）資訊保護

KidsLearn 定位為面向家長的管理工具，而非兒童嚮應用：所有內容由家長建立與管理。應用不提供聊天、評論、公開主頁、內容推薦/發現、陌生人互動或使用者生成內容的公開發布功能。

  • 我們不收集、不出售、不向第三方披露兒童個人資訊。兒童相關的學習記錄（暱稱、頭像、課程、作業、習慣、積分等）全部由家長錄入，僅儲存在家長自己的 iCloud 帳戶中，開發者不接觸、不可見。
  • 無公開使用者生成內容：家長錄入的文字內容僅在家長透過 iCloud 隱私共享（CKShare）一對一邀請的家庭成員之間可見，不向公眾開放、無陌生人可見渠道、無搜尋或推薦機制，因此本應用不涉及公開使用者生成內容（UGC）相關的社交風險。
  • 家長控制工具：應用提供「兒童裝置鎖（PIN 保護）」——開啟後配置類功能被隱藏，退出需輸入 PIN；修改或重置 PIN 需透過系統生物識別或裝置密碼驗證。家長可藉此限制兒童對設定與購買的訪問。
  • 兒童 Apple ID：若家長把孩子空間共享給兒童 Apple ID，該帳號依法由家長建立與管理，共享範圍始終由家長掌控，可隨時停止共享。
  • 關於家長同意：由於本應用完全不收集兒童個人資訊，美國 COPPA、歐盟 GDPR（兒童條款）以及中國《兒童個人資訊網路保護規定》所要求的「可驗證家長同意」機制在本應用中不適用；我們也不需要為此收集家長身份資訊。家長可隨時刪除任一「孩子空間」及其全部資料，刪除即刻生效。
  • 我們遵循中國《個人資訊保護法》《兒童個人資訊網路保護規定》，並參照 COPPA、GDPR 對兒童資料的保護原則：最小必要、家長控制、不共享、不出售、不用於廣告或畫像。
  • 如家長希望查詢、更正或徹底刪除與兒童相關的資訊，可在應用內直接操作，或傳送郵件至 fathyzhou@qq.com，我們將提供協助。

五、資料儲存、安全與刪除

  • 全部資料儲存在你的 Apple ID 對應的 iCloud 帳戶中，受 Apple 的加密與訪問控制保護，我們沒有任何服務端副本。
  • 解除安裝 App 不會自動刪除 iCloud 中的資料（便於換機恢復）。如需徹底刪除：在 iPhone/iPad 進入「設定 → 頂部 Apple ID → iCloud → 管理帳戶儲存空間 → KidsLearn → 刪除資料」；或在 App 內進入「我的 → 孩子空間」，刪除對應空間；也可發郵件至 fathyzhou@qq.com 請求刪除協助。
  • 少量介面偏好（如語言、展示設定）儲存在裝置本地（系統 UserDefaults），不會離開你的裝置，也不與 iCloud 同步。
  • 請妥善保管你的 Apple ID 與裝置鎖屏密碼，這是保護這些資料的主要手段。

六、購買與付款

KidsLearn 免費下載並提供本地 7 天試用；完整版為一次性買斷（非訂閱型內購，無自動續費）。所有支付由 Apple App Store（StoreKit）處理，我們不會收到或儲存你的支付卡資訊，也看不到你的完整帳戶資訊。內購已開啟「家人共享」，家庭成員無需重複購買。

七、政策更新

如本政策發生變更，我們會更新本頁面並修改頂部的「生效日期」；若涉及重大變更（例如新增資料收集），將在應用內以顯著方式提示。建議你定期檢視本頁面以獲取最新內容。

八、聯絡我們

如你對本政策或資料處理有任何疑問、投訴或刪除請求，請傳送郵件至 fathyzhou@qq.com，我們通常在 3 個工作日內回覆。

支援與常見問題

換機 / 多裝置同步在各裝置上登入同一個 Apple ID 並開啟 iCloud 雲盤後開啟 KidsLearn，資料會自動同步。若長時間未同步，請檢查系統「設定 → Apple ID → iCloud」是否已登入且網路正常。
家人 / 孩子空間共享在 App 內使用「孩子空間分享」（基於 Apple CloudKit CKShare）生成連結，對方用其 Apple ID 接受即可。需要兩個不同的 Apple ID 才能完成測試。
恢復購買開啟付費頁，點選底部「恢復購買」，按系統提示用購買時使用的 Apple ID 驗證即可，不會重複扣費。
徹底刪除資料見上方「資料儲存、安全與刪除」章節。解除安裝 App 不會刪除 iCloud 資料。
拍照識字（OCR）使用 Apple Vision 在裝置端識別，無需聯網，圖片不上傳。
支援的語言簡體中文、繁體中文、English、日本語、Español、Português (BR)、Français、Deutsch、한국어、Русский（共 10 種）。
系統要求iOS / iPadOS 17.0 或更高版本（iPhone 與 iPad 通用，含桌面小元件）。

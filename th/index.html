โดยสรุป: LearnNest ไม่เก็บข้อมูลส่วนบุคคลใด ๆ ไม่มีระบบบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีการวิเคราะห์หรือโฆษณาจากบุคคลที่สาม ตารางเรียน การบ้าน นิสัย การแจ้งเตือน และคะแนนที่คุณบันทึก จะถูกเก็บในฐานข้อมูล iCloud ส่วนตัวของคุณเองเท่านั้น (Apple CloudKit) นักพัฒนาไม่สามารถอ่านหรือส่งออกข้อมูลเหล่านั้นได้ มีการล็อกอุปกรณ์ (PIN) ไว้ใช้เป็นการควบคุมโดยผู้ปกครอง และเนื้อหาการเรียนทั้งหมดสร้างและจัดการโดยผู้ปกครอง

นโยบายความเป็นส่วนตัว

1. ภาพรวม

LearnNest เป็นเครื่องมือจัดระเบียบการเรียนสำหรับผู้ปกครอง ครอบคลุมตารางเรียน การบ้าน นิสัย การแจ้งเตือน และระบบคะแนน/ของรางวัล พัฒนาโดยนักพัฒนาอิสระ (Frank Zhou) — ไม่มีเซิร์ฟเวอร์ของตัวเองและไม่มีฐานข้อมูลแบ็กเอนด์ นโยบายนี้อธิบายว่าเราจัดการ — หรือพูดให้ถูกคือไม่จัดการ — ข้อมูลของคุณอย่างไร

2. สิ่งที่เราเก็บ: ไม่มีอะไรเลย

LearnNest ไม่เก็บข้อมูลส่วนบุคคลใด ๆ อย่างเป็นรูปธรรม:

  • ไม่มีการสมัคร ไม่มีการล็อกอิน เราไม่ขอและไม่รับชื่อ อีเมล เบอร์โทร รายชื่อติดต่อ ตำแหน่งที่ตั้ง รูปภาพ หรือตัวระบุอื่นใด
  • ข้อมูลของคุณอยู่ใน iCloud ของคุณเอง ตารางเรียน การบ้าน นิสัย การแจ้งเตือน คะแนน และของรางวัลที่คุณสร้าง จะถูกเก็บในฐานข้อมูล iCloud ส่วนตัวของ Apple ID คุณ (Apple CloudKit, คอนเทนเนอร์ iCloud.com.frankzhou.KidLearn) ข้อมูลเป็นของคุณและ Apple เป็นผู้เก็บรักษา นักพัฒนาเข้าถึง อ่าน หรือส่งออกไม่ได้
  • การแชร์ระดับครอบครัวและพื้นที่การเรียน สร้างบน Apple CloudKit CKShare ข้อมูลแชร์เฉพาะกับ Apple ID ที่คุณเชิญอย่างชัดเจน (ปกติคือสมาชิกครอบครัว) การควบคุมอยู่ในมือคุณและยกเลิกการแชร์ได้ทุกเมื่อ

ความสามารถของอุปกรณ์และสิทธิ์ของระบบ:

  • การแจ้งเตือน — ใช้เพื่อส่งการแจ้งเตือนการเรียนที่คุณสร้างเองเท่านั้น ไม่มีเนื้อหาโฆษณาหรือการตลาด "การแจ้งเตือนระยะไกล" ใช้เป็นตัวกระตุ้นเงียบสำหรับการซิงค์ iCloud เท่านั้น ไม่เคยแสดงการเตือนที่มองเห็นได้
  • รูปภาพ (ตัวเลือกรูปของระบบ) — ฟังก์ชัน "สแกนข้อความ (OCR)" ของหน้าการบ้าน เลือกรูปผ่านตัวเลือกรูปภาพระบบของ Apple (PhotosPicker) แอปรับเฉพาะรูปเดียวที่คุณเลือก ไม่สามารถเข้าถึงรูปอื่นในคลัง และไม่ขอสิทธิ์เข้าถึงคลังรูปภาพ การจดจำทำงานบนอุปกรณ์ทั้งหมดด้วยเฟรมเวิร์ก Vision ของ Apple ทั้งรูปและผลลัพธ์ไม่เคยถูกอัปโหลด และไม่บันทึกรูปต้นฉบับ แอปไม่ใช้กล้องและไม่ขอสิทธิ์กล้อง รูปโปรไฟล์ของพื้นที่การเรียนทำงานเช่นเดียวกัน: อ่านเฉพาะรูปที่เลือก บีบอัด และเก็บในบัญชี iCloud ของคุณเองเท่านั้น — ไม่เคยอัปโหลดขึ้นเซิร์ฟเวอร์ใด
  • Face ID / Touch ID / รหัสของเครื่อง — ใช้เพื่อยืนยันตัวตนบนอุปกรณ์นี้เท่านั้น เมื่อผู้ปกครองแก้ไขหรือรีเซ็ต PIN ของการล็อกอุปกรณ์ หรือปิดโหมดล็อก การยืนยันทำโดย iOS แอปไม่รับ ไม่อ่าน และไม่เก็บข้อมูลชีวมิติ
  • คลิปบอร์ด — อ่านครั้งเดียว เฉพาะเมื่อคุณแตะ "วาง" เพื่อสร้างรายการการบ้าน ข้อความประมวลผลบนอุปกรณ์ ไม่เคยอัปโหลดหรือบันทึก แอปไม่เข้าถึงคลิปบอร์ดในเวลาอื่นใด
  • สิทธิ์ที่เราไม่ขอเลย — ไม่มีตำแหน่งที่ตั้ง รายชื่อติดต่อ ปฏิทิน การเตือนความจำ ไมโครโฟน กล้อง หรือการติดตามแอป นอกเหนือจากข้างต้น แอปไม่ประกาศสิทธิ์อื่นใด

3. บุคคลที่สาม การติดตาม และโฆษณา: ไม่มี

  • ไม่มีโค้ดบุคคลที่สามเลย — โปรเจกต์ไม่พึ่งพา Swift Package, CocoaPods หรือไลบรารีบุคคลที่สามใด ไม่มี SDK โฆษณา ไม่มี SDK วิเคราะห์ (ไม่มี Firebase ฯลฯ) ไม่มีรายงานข้อขัดข้อง การอ้างอิงแหล่งที่มา หรือการตลาดแบบพุช
  • ไม่มีการติดตาม — ไม่มี IDFA ไม่มีข้อความ App Tracking Transparency ไม่มีการติดตามข้ามแอปหรือเว็บไซต์ ไม่มีคุกกี้ติดตาม ฟิงเกอร์ปรินต์อุปกรณ์ หรือตัวระบุภายในเครื่อง
  • เราไม่ขาย ไม่แชร์ หรือแลกเปลี่ยนข้อมูลผู้ใช้ และไม่มีข้อมูลใดเข้าร่วมรูปแบบการสร้างรายได้ใด ๆ ไม่ใช้ข้อมูลเพื่อโฆษณาหรือสร้างโปรไฟล์ผู้ใช้
  • คำขอเครือข่ายทั้งหมดไปยังบริการของ Apple ยกเว้นการโหลดหน้านโยบายนี้ — การซิงค์ iCloud (CloudKit) และการซื้อใน App Store (StoreKit) ทั้งสองอยู่ภายใต้นโยบายความเป็นส่วนตัวของ Apple — ดู นโยบายความเป็นส่วนตัวของ Apple (รายการ "นโยบายความเป็นส่วนตัว" และ "การสนับสนุน" ในแอป เปิดในเครื่องอ่านในตัวที่ไม่มีแถบที่อยู่และไม่ออกจากแอป: โหลดเฉพาะหน้านี้ ปิด JavaScript ไม่เขียนคุกกี้หรือข้อมูลเว็บ และบล็อกการไปยังโดเมนอื่น หน้านี้โฮสต์บนบริการโฮสติ้งแบบสถิตของบุคคลที่สาม (GitHub Pages) การโหลดหน้าคือคำขอเครือข่ายเดียวที่แอปส่งไปยังบริการนอก Apple และไม่มีบัญชีหรือตัวระบุอุปกรณ์)

4. ความเป็นส่วนตัวของผู้เยาว์

LearnNest เป็นเครื่องมือจัดการสำหรับผู้ปกครอง ไม่ใช่แอปสำหรับผู้เยาว์โดยตรง: เนื้อหาทั้งหมดสร้างและจัดการโดยผู้ปกครอง แอปไม่มีการสนทนา ความคิดเห็น โปรไฟล์สาธารณะ การค้นพบหรือแนะนำเนื้อหา การติดต่อกับคนแปลกหน้า หรือการแชร์เนื้อหาที่ผู้ใช้สร้างแบบสาธารณะ

  • เราไม่เก็บ ไม่ขาย หรือเปิดเผยข้อมูลส่วนบุคคลของผู้เยาว์แก่บุคคลที่สาม บันทึกการเรียน (ชื่อเล่น อวตาร วิชา การบ้าน นิสัย คะแนน ฯลฯ) บันทึกโดยผู้ปกครองและเก็บในบัญชี iCloud ของผู้ปกครองเท่านั้น นักพัฒนาไม่มีสิทธิ์เข้าถึง
  • ไม่มีเนื้อหาผู้ใช้แบบสาธารณะ ข้อความที่ผู้ปกครองบันทึก มองเห็นได้เฉพาะสมาชิกครอบครัวที่ผู้ปกครองเชิญเป็นรายบุคคลผ่านการแชร์ iCloud ส่วนตัว (CKShare) ไม่มีผู้ติดตามสาธารณะ การเปิดเผยต่อคนแปลกหน้า การค้นหา หรือกลไกแนะนำ แอปจึงไม่มีความเสี่ยงทางสังคมของเนื้อหาสาธารณะ
  • การควบคุมโดยผู้ปกครอง แอปมี "ล็อกอุปกรณ์ (PIN)": เมื่อเปิดใช้งาน ฟังก์ชันตั้งค่าจะถูกซ่อนและการออกต้องใส่ PIN การแก้ไขหรือรีเซ็ตต้องยืนยันด้วยชีวมิติหรือรหัสของระบบ ผู้ปกครองใช้จำกัดการเข้าถึงการตั้งค่าและการซื้อได้
  • Apple ID ของผู้เยาว์ หากผู้ปกครองแชร์พื้นที่การเรียนไปยัง Apple ID ของผู้เยาว์ บัญชีนั้นจะถูกสร้างและจัดการโดยผู้ปกครองตามกฎของ Apple การแชร์ยังอยู่ในการควบคุมของผู้ปกครองและหยุดได้ทุกเมื่อ
  • เรื่องความยินยอมของผู้ปกครอง เนื่องจากแอปไม่เก็บข้อมูลส่วนบุคคลใด ๆ เกี่ยวกับผู้เยาว์ กลไก "ความยินยอมที่ตรวจสอบได้ของผู้ปกครอง" ตามที่ COPPA (สหรัฐฯ), GDPR (บทบาทเกี่ยวกับผู้เยาว์, EU) และกฎการคุ้มครองข้อมูลส่วนบุคคลออนไลน์ของผู้เยาว์ของจีนกำหนด จึงไม่มีการนำมาใช้ และเราไม่จำเป็นต้องเก็บข้อมูลตัวตนของผู้ปกครองเพื่อจุดประสงค์นั้น ผู้ปกครองสามารถลบพื้นที่การเรียนใด ๆ พร้อมข้อมูลทั้งหมดได้ทุกเมื่อ และการลบมีผลทันที
  • เราปฏิบัติตามกฎหมายคุ้มครองข้อมูลส่วนบุคคลของจีนและกฎการคุ้มครองข้อมูลออนไลน์ของผู้เยาว์ และสอดคล้องกับหลักการ COPPA/GDPR: ลดข้อมูลให้น้อยที่สุด การควบคุมโดยผู้ปกครอง ไม่แชร์ ไม่ขาย ไม่มีโฆษณาหรือการสร้างโปรไฟล์
  • ผู้ปกครองที่ต้องการตรวจสอบ แก้ไข หรือลบอย่างถาวรซึ่งข้อมูลในพื้นที่การเรียน ทำได้ในแอป หรือส่งอีเมลไปที่ Your.LearnNest@outlook.com เพื่อขอความช่วยเหลือ

5. การเก็บรักษา ความปลอดภัย และการลบข้อมูล

  • ข้อมูลทั้งหมดอยู่ในบัญชี iCloud ของ Apple ID คุณ ซึ่งได้รับการปกป้องด้วยการเข้ารหัสและการควบคุมการเข้าถึงของ Apple เราไม่เก็บสำเนาบนเซิร์ฟเวอร์
  • การลบแอปไม่ได้ลบข้อมูล iCloud โดยอัตโนมัติ (เพื่อให้คุณกู้คืนได้บนอุปกรณ์ใหม่) หากต้องการลบทุกอย่าง: บน iPhone/iPad ไปที่ การตั้งค่า → Apple ID ของคุณ → iCloud → จัดการพื้นที่จัดเก็บ → LearnNest → ลบข้อมูล; หรือลบพื้นที่การเรียนที่ต้องการในแอปที่ ของฉัน → พื้นที่การเรียน; หรือส่งอีเมลไปที่ Your.LearnNest@outlook.com เพื่อขอความช่วยเหลือในการลบ
  • การตั้งค่าอินเทอร์เฟซบางอย่าง (ภาษา ธีม) เก็บในเครื่องของคุณเท่านั้น (UserDefaults ของระบบ) ไม่ออกจากอุปกรณ์และไม่ซิงค์ขึ้น iCloud
  • รักษา Apple ID และรหัสของเครื่องให้ปลอดภัย — นั่นคือการป้องกันที่สำคัญที่สุดของข้อมูลเหล่านี้

6. การซื้อและการชำระเงิน

LearnNest ดาวน์โหลดฟรีพร้อมทดลองใช้ในเครื่อง 7 วัน เวอร์ชันเต็มเป็นการซื้อครั้งเดียว (ไม่ใช่สิ่งที่ใช้แล้วหมด ไม่มีการสมัครสมาชิก ไม่มีการต่ออายุอัตโนมัติ) การชำระเงินทั้งหมดดำเนินการโดย Apple App Store (StoreKit) เราไม่รับหรือเก็บข้อมูลบัตรของคุณและไม่เห็นรายละเอียดบัญชีฉบับเต็ม เปิดใช้ Family Sharing แล้ว สมาชิกครอบครัวไม่ต้องซื้อซ้ำ

7. การเปลี่ยนแปลงนโยบายนี้

หากนโยบายนี้มีการเปลี่ยนแปลง เราจะอัปเดตหน้านี้และ "วันที่มีผลบังคับ" ด้านบน การเปลี่ยนแปลงที่สำคัญ (เช่น การเริ่มเก็บข้อมูลชนิดใหม่) จะประกาศอย่างชัดเจนในแอปด้วย โปรดตรวจสอบหน้านี้เป็นระยะเพื่อดูเวอร์ชันล่าสุด

8. ติดต่อเรา

อุปกรณ์ใหม่ / ซิงค์ข้ามอุปกรณ์ล็อกอินด้วย Apple ID เดียวกันบนทุกอุปกรณ์โดยเปิด iCloud Drive ไว้ ข้อมูลจะซิงค์อัตโนมัติ หากซิงค์ค้าง ให้ตรวจสอบที่ การตั้งค่า → Apple ID → iCloud
แชร์ครอบครัว / พื้นที่การเรียนใช้ "แชร์พื้นที่" ในแอป (Apple CloudKit CKShare) ผู้รับยอมรับด้วย Apple ID ของตนเอง การทดสอบต้องใช้ Apple ID สองบัญชีที่ต่างกัน
กู้คืนการซื้อแตะ "กู้คืนการซื้อ" ที่ด้านล่างของหน้าชำระเงิน — ไม่มีค่าใช้จ่ายเพิ่มเติม
ลบข้อมูลทั้งหมดดูหัวข้อ 5 ด้านบน การลบแอปไม่ได้ลบข้อมูล iCloud
สแกนข้อความ (OCR)ทำงานบนอุปกรณ์ทั้งหมดด้วย Apple Vision ไม่มีการอัปโหลด ไม่ต้องใช้เครือข่าย
ภาษาที่รองรับ22 ภาษา: จีนตัวย่อและตัวเต็ม อังกฤษ ญี่ปุ่น เกาหลี สเปน โปรตุเกส (BR) ฝรั่งเศส เยอรมัน อิตาลี ดัตช์ โปแลนด์ สวีเดน นอร์เวย์ (bokmål) เดนมาร์ก อินโดนีเซีย มลายู ฟิลิปปินส์ ตุรกี เวียดนาม รัสเซีย และไทย
